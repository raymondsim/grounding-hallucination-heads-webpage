# The Model Knows Where to Look — AACL 2026

A minimal responsive landing page for Mong Yuan Sim's research paper, with links to the paper, code, email, WeChat, LinkedIn and Google Scholar.

## Website

The page is implemented in `index.html` as a static, dependency-free HTML/CSS/JavaScript page. Open that file directly in your browser to preview it on a computer or phone.

## Publish via GitHub Pages

In this repository, choose **Settings → Pages → Deploy from a branch → main → /(root)** and save. Publishing is a separate step from committing code.

Expected URL after publishing: `https://raymondsim.github.io/grounding-hallucination-heads-webpage/`

## Paper PDF

Until the PDF is provided, **Read the Paper** intentionally links to `https://github.com/raymondsim/grounding-hallucination-heads`, the same destination as **Source Code**. When the PDF is ready, add it to this repository and change the first button's link to the PDF location.

The WeChat card copies `raymondsim00`. Both email addresses are separately clickable.
